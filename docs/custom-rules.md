# 自定义规则

未来这里用于记录 GKD-Merged 自己维护的补充规则。

## 设计目标

自定义规则应该与上游规则分开管理，避免上游更新时覆盖本项目自己的修复。

计划结构：

```text
custom/
├── apps/
└── global/
```

## 提交自定义规则前

建议先使用 GKD 的快照功能获取真实 UI 信息，再根据快照编写选择器。

尤其是按钮位置、文本、`clickable`、`visibleToUser` 等属性发生变化时，不建议直接复制旧规则修改文字。

## 推荐提供的信息

- APP 包名
- APP 版本
- GKD 版本
- 规则用途
- 快照链接
- 事件日志（如果有）
- 复现步骤

## 微信等复杂页面

对于 UI 频繁变化的 APP，应尽量使用稳定的文本、resourceId 或结构关系，而不是固定坐标。若确实需要位置选择器，应同时说明适用版本。
