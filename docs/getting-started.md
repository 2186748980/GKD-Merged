# 快速开始

如果你第一次使用 GKD，不用担心。按照下面几步即可完成配置。

## 1. 安装 GKD

请前往 [GKD 官方仓库](https://github.com/gkd-kit/gkd) 获取最新版。

## 2. 添加 GKD-Merged

复制下面的订阅地址：

```text
https://2186748980.github.io/GKD-Merged/gkd/gkd.json5
```

在 GKD 中进入订阅管理，添加远程订阅并粘贴地址。

## 3. 开启需要的规则

订阅更新后，可以按照自己的需求启用规则组。不建议一次性开启所有规则；如果某个 APP 出现误触，优先关闭对应规则组。

## 4. 更新

GKD-Merged 会自动检查上游订阅并重新构建。你只需要让 GKD 定期检查订阅即可。

## 常见问题

### 为什么订阅很大？

这是一个多源综合订阅。它会保留多个上游项目中的互补规则，而不是只选择一个来源。

### 为什么某个规则没有更新？

上游项目的更新需要先被本项目拉取、解析并合并。部分规则也可能因为重复、冲突或上游停更而保持旧版本。

### 如何报告失效规则？

建议提交 Issue，并尽量提供 APP 版本、GKD 版本、规则名称以及 GKD 快照或事件信息。
