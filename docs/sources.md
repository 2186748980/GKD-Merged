# 上游来源

GKD-Merged 是一个社区维护的多源聚合项目，不属于 GKD 官方。

## 当前来源

| 来源 | 定位 | 优先级 |
|---|---|---:|
| [Lin-arm/GKD_subscription](https://github.com/Lin-arm/GKD_subscription) | 主要活跃来源 | 100 |
| [ganlinte/GKD-subscription](https://github.com/ganlinte/GKD-subscription) | 活跃补充来源 | 90 |
| [AIsouler/GKD_subscription](https://github.com/AIsouler/GKD_subscription) | 历史规则补充 | 50 |
| [Adpro-Team/GKD_subscription](https://github.com/Adpro-Team/GKD_subscription) | 历史规则补充 | 40 |

## 合并原则

高优先级来源优先处理；低优先级来源主要用于补充高优先级来源缺少的 APP 和规则。

同一 APP、同名规则组出现时，会尝试进行规则级去重，而不是简单覆盖整个规则组。

## 关于历史来源

已经停止活跃维护的来源仍可能包含有价值的旧规则，因此本项目会在兼容的前提下保留它们作为补充。但旧规则不代表一定适用于最新版 APP。

## 版权与归属

本项目只是聚合和构建工具。各规则的版权、许可证及原作者归属以对应上游项目为准。请尊重各上游项目的许可证和贡献者。
