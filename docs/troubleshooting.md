# 故障排查

## GKD 提示“解析订阅失败”

先确认订阅地址：

```text
https://2186748980.github.io/GKD-Merged/gkd/gkd.json5
```

如果仍然失败，请打开仓库的 Actions，确认最近一次构建是否成功。

## 某个 APP 没有规则

这可能意味着：

1. 当前四个来源都没有该 APP；
2. 上游规则已经删除；
3. 规则被合并去重；
4. APP 更新后 UI 已经变化。

## 规则存在但没有触发

请优先检查：

- APP 版本是否变化；
- GKD 无障碍服务是否正常；
- 规则组是否启用；
- 规则的 activity、文本或 resourceId 是否已经变化。

如果可以，提供 GKD 快照和事件日志，这通常比截图更容易定位问题。

## 上游构建失败

项目会优先使用已有缓存继续构建。若某个来源连续失败，应检查 `gkd/merge-status.json` 中的状态，并在对应上游仓库确认订阅地址是否变化。
